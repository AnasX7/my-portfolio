# Triage roles

Use the triage roles below to interpret a triage decision. Before applying a label, read its verified Linear label name or ID from the triage section of the [private workflow configuration](../../AGENTS.md#private-workflow-configuration). If the role has no verified mapping, record the decision and report label application as pending.

| Role              | Meaning                                              |
| ----------------- | ---------------------------------------------------- |
| `needs-triage`    | Maintainer evaluation is needed.                     |
| `needs-info`      | More information is needed.                          |
| `ready-for-agent` | The issue is fully specified and ready for an agent. |
| `ready-for-human` | The issue requires human implementation.             |
| `wontfix`         | The maintainer declined the work.                    |
