# Issue tracker

Use **Linear** for portfolio work items. Read the verified project link and ID, team, and workflow states from the Linear section of the [private workflow configuration](../../AGENTS.md#private-workflow-configuration). Scope project-wide searches and new issues to the verified project.

Read the parent, specification, comments, and blockers before implementation. Use Linear's sub-issue and blocking relationships when breaking down work. See [domain documentation](domain.md) for specs and [triage roles](triage-labels.md) for triage.

For authorized status updates, use the configured workflow states when starting work, handing it off for review, and completing it.

## Definition of Done

Meet the issue's acceptance criteria, run the relevant checks, and verify the change through its normal entry point. Record the result and evidence in the issue. Keep it open while required verification or review is pending.
